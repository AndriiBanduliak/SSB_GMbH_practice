
Автоматизация конвертации YouTube Shorts в TikTok.
# youtube-tiktok

Автоматический скрипт для поиска Shorts на YouTube, их обработки и публикации в TikTok.

## Описание

Этот проект предназначен для автоматизации процесса кросс-постинга коротких видеороликов. Он ищет подходящие видео на YouTube, загружает их, обрабатывает (например, меняет формат или обрезает), генерирует заголовки и описания, а затем публикует их в TikTok по расписанию.

**Внимание:** Автоматическая загрузка и публикация контента может нарушать авторские права и условия использования платформ (YouTube и TikTok). Используйте этот скрипт ответственно и только для контента, на который у вас есть разрешение, или который разрешен соответствующими лицензиями (например, Creative Commons с условиями использования).

## Структура проекта

- `src/`: Основной исходный код, разбитый на модули по функциональности.
- `scripts/`: Скрипты для инициализации и запуска.
- `tests/`: Юнит-тесты.
- `requirements.txt`: Список зависимостей Python.
- `README.md`: Этот файл.
- `.gitignore`: Файл для игнорирования ненужных файлов в Git.

## Установка

1.  Клонируйте репозиторий:
    ```bash
    git clone <ссылка_на_ваш_репозиторий>
    cd youtube-tiktok
    ```
2.  (Опционально) Создайте и активируйте виртуальное окружение:
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    ```
3.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
4.  Установите `ffmpeg`. Этот инструмент необходим для обработки видео. Инструкции по установке зависят от вашей операционной системы (apt, brew, chocolatey или скачивание с сайта ffmpeg.org).
5.  Настройте файл `src/config.py`. **Важно:** Не коммитьте чувствительные ключи API напрямую. Рекомендуется использовать переменные окружения или файл `.env` (который нужно добавить в `.gitignore`).

## Настройка

Отредактируйте файл `src/config.py`, чтобы указать ваши ключи API YouTube, учетные данные TikTok (если используется Selenium) и другие необходимые настройки.
