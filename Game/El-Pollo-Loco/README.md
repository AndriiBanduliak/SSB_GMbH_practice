# El Pollo Loco - Мексиканское Приключение

## Описание
El Pollo Loco - это захватывающая игра-платформер с мексиканской тематикой. Играйте за персонажа Пепе, собирайте монеты, сражайтесь с курицами и победите босса!

## Особенности игры
- 🎮 Плавная анимация персонажей
- 🪙 Система сбора монет
- ⚔️ Боевая система с броском бутылок
- 🏆 Таблица лидеров (Top 20)
- 🎵 Фоновая музыка и звуковые эффекты
- 📱 Адаптивный дизайн для разных устройств

## Управление
- **← →** - Движение влево/вправо
- **A** - Движение влево
- **D** - Бросок бутылки
- **↑** или **W** - Прыжок
- **ПРОБЕЛ** - Прыжок

## Цель игры
1. Собирайте монеты для увеличения счета
2. Избегайте столкновений с курицами
3. Бросайте бутылки в врагов
4. Победите босса в конце уровня

## Запуск игры
1. Откройте `index.html` в веб-браузере
2. Или запустите локальный сервер:
   ```bash
   python -m http.server 8000
   ```
   Затем откройте `http://localhost:8000`
