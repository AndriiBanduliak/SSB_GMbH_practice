# SSB_GMbH_practice

This repository contains a collection of projects and practical tasks developed during my internship at **SSB Security GmbH**.  

The projects cover a wide range of topics, including:  
- Telegram bots and automation tools  
- Simple games and educational applications  
- File scanning and antivirus scripts  
- Data analysis and reporting tools  
- Utility scripts for various tasks  

The main language is **Python**, with additional use of **Shell, JavaScript, PowerShell, Cython, and HTML** for supporting tasks.  

Although the projects are diverse and not organized under a single structure, the repository demonstrates my ability to work with different technologies, experiment with ideas, and implement solutions for various domains.
